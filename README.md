# InnoCamp BW 2026

Kleine, responsive One-Page-Website zum InnovationCamp Baden-Württemberg im Silicon Valley vom 9. bis 20. November 2026.

Die Seite besteht nur aus HTML, CSS und etwas JavaScript. Es ist kein Build-Schritt nötig.

## Veröffentlichung

Der GitHub-Workflow veröffentlicht die Seite bei jedem Push auf `main`. Unter **Settings → Pages → Build and deployment** muss dafür einmalig **GitHub Actions** ausgewählt sein.
